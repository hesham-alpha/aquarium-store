# Aquarium Store

A small static game storefront with an ocean-inspired design. The site is built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. Game artwork is loaded from Steam, and game purchase and trailer links open Steam and YouTube.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the site automatically whenever changes are pushed to the `main` branch.
